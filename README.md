# Sagai Framework: overview sheets and community feedback

This repository holds the one-page A3 overview of each Sagai framework: Sagai ADLC, Sagai Governance, Sagai Architecture and Sagai Strategy. You can provide your thoughts and feedback in this forum to help improve the framework.

## What is here

Four A3 PDFs, one for each framework:

- `ADLC_Process_Infographic_A3.pdf`
- `Governance_Process_Infographic_A3.pdf`
- `Architecture_Process_Infographic_A3.pdf`
- `Strategy_Process_Infographic_A3.pdf`

Each one is a picture of the page, so the text cannot be selected or searched, and a screen reader cannot read it. The PDFs are licensed under CC BY 4.0, (c) 2026 Aquasila Pty Ltd. The terms and the credit line for each are in [LICENSE](LICENSE).

## What is not here

The frameworks themselves. If you do not have a copy, read the terms and ask for the full copy at https://sagai.com.au/. You can also follow the Sagai page at https://www.linkedin.com/company/sagai-framework.

## Feedback

Start a discussion in the Discussions tab. Say which framework and which part of the overview you mean, and what you would change and why. Please do not post confidential or client information, or anything personal. Discussions are public, and your GitHub username shows with what you write.

Sagai decides what changes. Changes that are made appear in later releases of the frameworks.
